---
name: Prompt polish
description: Use when the person wants a rough idea turned into a clear prompt: for a routine, a bot's role, or another AI tool. Not for doing the task itself.
---
**When to use:** "Write a good prompt for…", "improve this prompt", "turn this into a routine prompt", "what should I tell the image AI?".

**You'll need:** Their rough idea. memory_search for their preferences that belong in it (language, tone, what to leave out).

**Steps:**
1. Find out what it's for: a routine you'll run on a schedule, another bot, an image or video tool, or a chat with some other AI. That decides the form.
2. Pin down the goal in one sentence and what a good result looks like. If one or two things decide the result and you can't tell (audience, length, format), ask them in one short message and wait.
3. Write the prompt with these parts, each only if it helps: the task, first and plainly; context the reader can't know; inputs (what it gets, where from); the steps or the thinking to do, when order matters; the output (format, length, language); limits (what to leave out, when to stop and say so); one short example if the format is unusual.
4. For a routine: say what to check, when to stay quiet, and what's worth a message. For an image tool: subject, setting, style, light, colours, framing and aspect ratio, in plain phrases.
5. Cut the vague: "be detailed", "act as a world-class expert", "think step by step" unless steps follow. Replace them with the specifics they stand for.

**Check:** Someone with no context could do the task from the prompt alone; every line changes the result; it's as short as it can be.

**Return:** The prompt in a copyable block, then two or three lines on what you added and why. For a routine, offer to create it (routine_create) with this prompt.

**Stop and ask if:** The goal is still unclear after one question, or the prompt is meant to get around another tool's rules: don't write that one.
