---
name: Memory check
description: Use when the person asks what you remember about them, or to clean up memory. Not for saving one new fact (just save it).
---
**When to use:** "What do you know about me?", "clean up your memory", "you keep getting X wrong".

**You'll need:** memory_search, memory_store (with supersedes, to correct one), memory_forget.

**Steps:**
1. Search memory for what matters to them: who they are, people, work, home, preferences, open tasks. Use several short searches, not one.
2. Sort what you find: about them, preferences and standing rules, open tasks, everything else.
3. Mark what looks wrong:
   - two memories that say opposite things, or an old value next to a new one;
   - tasks that are done, or dated plans that are past;
   - secrets (passwords, codes, card or ID numbers): those go in Saved logins or a password manager, never memory;
   - one-off chat details that won't matter again;
   - one memory holding several facts (better split).
4. For each, propose one change: forget it, correct it (memory_store with supersedes), or split it.

**Check:** You change nothing before they say which; corrections replace the old memory, never sit next to it.

**Return:** What you know, grouped and short, then the proposed changes as a numbered list, then "Which ones?". After they pick, say what changed.

**Stop and ask if:** You can't tell which of two memories is current, or a memory is about someone else and reads as private.
